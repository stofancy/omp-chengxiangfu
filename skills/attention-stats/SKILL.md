# 注意力统计

统计用户在一段时间里花了多少注意力，按天和按任务各给一张表。只读已有数据，不新增任何记录。

## 做法

1. 确定范围：用户说了范围就换算成 `--since <YYYY-MM-DD>` 和 `--until <YYYY-MM-DD>`（含当天）；没说就不带参数，默认最近 7 天。
2. 在本技能目录下运行脚本（`<技能目录>` 就是本文件所在目录）：

   ```
   bun <技能目录>/stats.ts --since 2026-11-10 --until 2026-11-17
   ```

   数据目录和会话目录一般不用指定（默认 `~/.local/share/chengxiangfu` 和 `~/.omp/agent/sessions`），需要时用 `--data`、`--sessions` 覆盖。
3. 把脚本输出的两张表**原样**贴给用户，不改数字、不重排。
4. 表后补一两句观察，比如哪天最忙、注意力集中在哪个任务、回复里有多少不是用户发话引起的、未归类占比高不高。只说数据能直接看出来的，不猜原因。

## 口径（用户问起时再解释）

- 用户消息：只算用户亲手输入的，不含工具结果、系统和插件注入的消息，也不含子代理的会话。
- 活跃分钟：同一天里相邻两条消息间隔不超过 5 分钟算连续活跃，间隔累加；落单的一条记 1 分钟。
- 给你读的回复：主会话里不带工具调用、有正文的回复，按不含空白的字数算。「不是你发话引起的」是主会话被子代理交回或外部消息叫醒之后写的。
- 按任务：一条消息算到哪个任务，看三样——正文里出现的任务编号（如 PROJ-123）；这一轮里主会话把话转给了哪个任务的负责 agent；这条消息到下一条之间同一个会话记下的决定、纠正和立项。都没有的进「未归类」。决定、提问、纠正数来自任务表记录。
- 撤回的提问：主会话登记之后自己关掉的提问（问了不该问的）。
- 远端写入：任务表记下的远端写入次数；「之前 30 分钟内没有你的决定」只是提示去看一眼，不等于没经同意。
- 日期按运行机器的本地时区。

脚本报错时把错误原样告诉用户，不要自己估算数字。
